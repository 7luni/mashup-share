# Mashup Share

Open any level's info page and tap the **Mashup** button (left side menu).

- **Upload mine** – pick an `.mp3`, `.ogg` or `.wav` file (max 20 MB). Each player gets **one mashup per level**; uploading again replaces yours.
- **Browse** – see everyone's mashups for that level and tap **Use** to play one.
- **Original** – go back to the level's normal song.

Requires a Mashup Share server (included in the source under `server/`). Set its address in the mod settings.
